Ch01. 만능 상자 let, 배열과 객체, 그리고 JSON 포장하기

console.log 출력, let 변수의 자유로운 변신(동적 타이핑), 객체에서 값 꺼내는 2가지 방법, 복잡한 중첩 데이터 탐색과 JSON.stringify

🎙️
1타 강사의 비전공자 눈높이 비유 특강!
자바(Java)를 배울 때는 "김치통(String)엔 김치만 넣고, 물병(int)엔 물만 넣어라!"라고 엄격하게 배웠죠?
하지만 자바스크립트의 let 변수는 '마법의 만능 택배 상자'입니다! 처음에 "강민재"(글자)를 넣었다가, 마음이 바뀌어서 123(숫자)을 넣어도 되고, 기차 칸 같은 [1, 2, 3](배열)이나 이름표 붙은 서랍장 { a: "강민재" }(객체)를 넣어도 상자가 알아서 모양을 바꿉니다!

1️⃣ 만능 상자 let과 객체(서랍장) 여는 2가지 방법

📄 ch01.js (1~21줄)

변수 하나(name)에 글자 → 숫자 → 배열([]) → 객체({})를 차례대로 바꿔 담아보고, 객체 서랍장에서 값을 꺼내는 두 가지 문법을 익힙니다.

  • 화면에 글자 찍기: 자바의 System.out.println() 대신 자바스크립트는 console.log()를 씁니다.
  • 0 나누기 0 (0 / 0): 자바에서는 에러가 터지며 프로그램이 멈추지만, 자바스크립트는 NaN(Not a Number, '계산할 수 없는 숫자가 아닌 값')을 쿨하게 출력하고 계속 진행합니다.
  • 대괄호 [] vs 중괄호 {} 구분법 (비전공자 암기팁!):
    • 대괄호 [1, 2, 3]은 '기차 칸(배열)'입니다. 방 이름표가 없어서 0번 칸, 1번 칸(인덱스 번호)으로 부릅니다.
    • 중괄호 { "a": "강민재", "b": "[1.2.3.4]" }는 '이름표가 붙은 서랍장(객체)'입니다.
  • 객체 서랍장에서 물건 꺼내는 2가지 방법:
    ① 점(.) 표기법: name.a → 'name 서랍장의 a 서랍 열어줘!' (제일 간단해서 실무에서 90% 사용!)
    ② 대괄호([]) 표기법: name["b"] → 큰따옴표로 이름표를 적어서 여는 방법!
💻 인텔리제이 ch01.js 원본 코드 & 주석 해설 
// [ch01.js 1~21줄 원본 코드]
console.log("안녕");
console.log(0 / 0);         // NaN (숫자가 아님)

let name = "강민재";        // 1) 처음엔 글자(문자열)를 담았다가
name = 123;                 // 2) 숫자도 담고
name = [1, 2, 3, 4, 5, 6, 7]; // 3) 배열(기차 칸)도 담고
name = {                    // 4) 객체(이름표 서랍장)도 담을 수 있음!
    "a": "강민재",
    "b": "[1.2.3.4]",
    "c": 1234,
};

console.log(name["b"]);     // 대괄호로 꺼내기 -> "[1.2.3.4]"
console.log(name.a);        // 점(.)으로 꺼내기 -> "강민재"

2️⃣ 아파트 주소 찾아가기(중첩 데이터) & JSON 진공 포장기

📄 ch01.js (23~51줄)

배열([]) 안에 객체({})가 겹겹이 들어있을 때 원하는 값을 쏙 빼내는 방법과, 서버로 데이터를 보낼 때 쓰는 JSON.stringify()입니다.

  • 택배 기사님처럼 주소 따라 읽기 (data[1].class2.student2.object.name):
    ① data는 바깥쪽이 대괄호 [ {class1...}, {class2...} ] 배열이죠? 두 번째 덩어리를 찾으려면 컴퓨터는 0부터 세니까 data[1]!
    ② 그 안은 전부 중괄호 {} 서랍장이니까 점(.)만 계속 찍고 들어가면 끝! .class2 → .student2 → .object → .name!
    💡 자바에서는 ((Student) data.get(0).get("class1")...)처럼 복잡하게 형변환까지 해야 했지만, JS는 점(.)만 찍으면 끝납니다!
  • JSON.stringify(data)가 뭔가요?:
    자바스크립트 객체는 컴퓨터 메모리에만 있는 입체 구조물입니다. 이걸 카카오톡이나 인터넷(서버)으로 전송하려면 한 줄짜리 평평한 글자(문자열, JSON)로 진공 포장해야 하는데, 그 포장 기계가 바로 JSON.stringify()입니다!
💻 인텔리제이 ch01.js 원본 코드 & 주석 해설 
// [ch01.js 23~51줄 원본 코드]
let data = [
    {   // <--- data[0] (0번 칸)
        class1: {
            student1: {
                id: 1,
                object: { name: "강민재", address: "서울" },
                createdAt: new Date("2025-10-20")
            }
        }
    },
    {   // <--- data[1] (1번 칸)
        class2: {
            student2: {
                id: 2,
                object: { name: "강민재", address: "제천" },
                createdAt: new Date("2025-10-22")
            }
        }
    }
];

// 1) 객체 배열을 전송용 JSON 글자로 진공 포장!
console.log(JSON.stringify(data));

// 2) 1번 칸 -> class2 -> student2 -> object -> name 꺼내기!
console.log(data[1].class2.student2.object.name); // "강민재"
